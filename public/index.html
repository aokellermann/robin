For Google / SSO accounts without a Robin password, or if you'd rather not type yours here.

How to get your token
  1. Sign in at dashboard.robinpowered.com as usual (Google sign-in works).
  2. Open the browser's developer tools (F12), choose the Network tab and reload the page.
  3. Click any request to api.robinpowered.com, find the Authorization request header and copy its value (Access-Token …) here.

The token is what the dashboard itself uses. It lasts about two weeks, is sent only to api.robinpowered.com, and is stored in this browser. It can't change your password.

Have a password? You can also mint one from a terminal without typing it into any website:

curl -u you@example.com https://api.robinpowered.com/v1.0/auth/users \
  -H 'Content-Type: application/json' -d '{"remember_me":true}'
